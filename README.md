### Для кроссбраузерного тестирования
1. Запуск с помощью

```bash
mvn clean test -Dbrowser=yandex
```
все тесты запускаются и не падают. Запуск делала с помощью конфигурации
"-ea -Dbrowser=yandex -Ddriver.version=138.0.7204.183 -Dwebdriver.yandex.bin=/Applications/Yandex.app/Contents/MacOS/Yandex"
